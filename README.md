# 🎮 Simon Says Game

A browser-based memory game built using **HTML, CSS, and JavaScript**. Test your memory by repeating the sequence of colored buttons as the game progresses through increasingly challenging levels.

## 📌 About the Project

Simon Says is a memory-based game in which players must remember and repeat a sequence of colors displayed by the game. With each level, the sequence gets longer, making the game progressively more challenging.

This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, and basic web development.

## ✨ Features

- 🎯 Simple and interactive gameplay.
- 🎨 Four colored buttons: Red, Yellow, Green, and Purple.
- 📈 Increasing difficulty with each level.
- ⚡ Visual feedback when buttons are flashed or pressed.
- 🏆 Tracks the highest score achieved during the session.
- 🔄 Restart the game after a game-over condition.
- 🌐 Runs directly in a web browser without additional installations.

## 🛠️ Technologies Used

- **HTML5** — Structures the game interface.
- **CSS3** — Styles the game layout, buttons, and visual effects.
- **JavaScript** — Implements game logic, sequence generation, user input, level progression, and score tracking.

## 🚀 Getting Started

Follow these steps to run the game locally.

### 📋 Prerequisites

- A modern web browser, such as Google Chrome, Firefox, or Microsoft Edge.
- A code editor such as Visual Studio Code (optional).
- Git installed on your system (if cloning the repository).

### 📥 Installation

**1. Clone the repository**

```bash
git clone https://github.com/GauravGuptaCoder1/simon-says-game.git
```

**2. Navigate to the project directory**

```bash
cd simon-says-game
```

**3. Run the game**

Open the `index.html` file in your web browser.

Alternatively, open the project in Visual Studio Code and run it using the Live Server extension.

## 🎮 How to Play

1. 🚀 Open the game in your browser.
2. ⌨️ Press any key on your keyboard to start.
3. 👀 Watch the colored button that flashes.
4. 🖱️ Click the corresponding button to repeat the sequence.
5. 🧠 Remember the sequence as a new color is added at each level.
6. 📈 Repeat the sequence correctly to advance to the next level.
7. ❌ Clicking the wrong button ends the game.
8. 🔄 Press any key to start a new game.
